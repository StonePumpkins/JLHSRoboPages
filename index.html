我们正在做什么

新的一届将减少外出比赛的频次，把更多精力投入到项目本身。新生进来后和老成员一起，选择一个感兴趣的方向，以老带新，从零开始做一个完整的项目。以下是我们当前推进中的几个方向。

01
LeRobot 机械臂套装
机械结构模仿学习强化学习进行中
基于 HuggingFace LeRobot 开源框架的机械臂项目。使用低成本舵机搭建六自由度机械臂，通过遥操作采集演示数据，训练模仿学习策略实现自主抓取。涵盖机械装配、电机控制、视觉感知、策略训练全流程。
Hardware
结构：3D 打印件 + 金属舵机
关节：多自由度串联构型
感知：USB 摄像头
主控：树莓派 / PC
Software
框架：LeRobot (HuggingFace)
策略：ACT / Diffusion Policy
训练：PyTorch + GPU
数据：遥操作演示采集
02
智能小车
传感器嵌入式 C路径规划进行中
智能小车项目覆盖从传感器驱动到自主决策的完整链路。集成超声波、红外、编码器等传感器，实现循迹、避障、自主导航等功能，是入门嵌入式开发的最佳实践平台。
Hardware
主控：STM32 / Arduino
测距：HC-SR04 超声波
避障：红外光电开关
电源：锂电池 + 稳压模块
Software
架构：状态机调度
算法：VFH / PID
通信：I2C + UART
调试：OLED 实时状态显示
03
全模态模型训练
大语言模型多模态前沿架构进行中
跟进 AI 前沿技术，研究并复现全模态大模型的核心架构与训练流程。从 Transformer 到多模态融合，从预训练到微调部署，理解当代 AI 系统的底层逻辑。面向对深度学习和 AI 原理有好奇心的同学。
Topics

多模态对齐与融合
预训练 / SFT / RLHF
推理优化与部署
Stack
语言：Python
